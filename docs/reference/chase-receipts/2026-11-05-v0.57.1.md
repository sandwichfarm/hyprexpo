## Publication boundary

An independent Arch candidate build of `403cff0` passed the four C++ suites,
pin checks and Make build with Hyprland 0.57.1-1, Aquamarine 0.16.0-1,
Lua 5.5.1-1 and GCC 16.2.1. Its unmodified artifact SHA256
`baadbe54fd5469adb2b4342147b2d06970fc1ca9ab40a14e2de9ac145fe2d6af`
passed the complete matching 0.57.1 VM suite. After unload, the process had
zero remaining mappings of that artifact, confirming actual library teardown.
This pre-tag build reports a development version; it is separate from the
eventual public release binary.

The tag workflow independently builds the Arch release artifact. Its provenance records the selected Lua module actually passed to Make, exact source/tag/VERSION, compositor and package versions, ELF dependencies and checksum. The public asset must be verified separately from these exact Nix artifacts, and must only be loaded into a matching compositor ABI.

Physical touchpad gestures, HDR hardware paths and generic distro HyprPM are outside the VM validation scope. Virtual input and Nix-assisted consumer proof do not imply those physical/package paths were exercised.
